Tourism: Description back to ToC

A more detailed description of the classes and properties of the SEGITTUR Tourism Ontology identified for reuse in the city tourism domain follows:

  • Class AccommodationEstablishment Accommodation types are subclasses: Hotel, Hostal, Hostel, Aparthotel, Vacation Rentals
    • AccommodationRating (object property) between an accommodation and its rating
    • numberOfAccommodationUnits (data property). Quantity of accommodation units, e.g., rooms
    • numberOfBeds (data property). Total number of beds
    • registrationNumber (data property). Identifier
    • hasDescription (object property) between a tourism entity (superclass) and its description
    • name (data property)
    • hasLocation (object property) between a place (superclass) and its location
    • hasContactPoint (object property) between a place (superclass) and its contact point
  • Class ContactPoint Contact details for the accommodation, which may include email, telephone, or a website
    • email (data property)
    • telephone (data property)
    • url (data property)
  • Class Rating Accommodation rating
    • ratingUnit (data property). Rating unit, e.g., "stars"
    • ratingValue (data property). Rating value, for example "3"
  • Class Description Short or long description of the accommodation
    • longDescription (data property)
    • shortDescription (data property)
  • Class Location Accommodation location
    • autonomousCommunity (data property)
    • country (data property)
    • county (data property)
    • province (data property)
    • locality (data property)
    • postal code (data property)
    • street address (data property)
    • gsp:lat and gsp:long. Because it is a subclass of gsp:Feature, the coordinates, latitude and longitude of the accommodation are represented
  • Class HistoricalOrCulturalResource Historical or cultural resource. The resource types are subclasses: Alcazar, Amphitheater, Acueduct, etc.
    • name (data property)
    • hasLocation (object property) between a place (superclass) and its location
    • hasDescription (object property) between a tourism entity (superclass) and its description

Figure 1 graphically illustrates the concepts from the SEGITTUR ontology that have been reused:

One of the central concepts is estur:AccommodationEstablishment, which relates to other classes such as estur:ContactPoint and estur:Location (as it is a subclass of estur:Place). The estur:Location class represents the accommodation's location, specified via its latitude, longitude, country, province, locality, postal code, and address.

It also relates to estur:Description (as it is a subclass of estur:TourismEntity). The class relates to estur:Rating to indicate the establishment's classification in a specific unit of measurement—for example, "Stars"—and to estur:PriceSpecification.

It also possesses properties linked to SKOS taxonomies: estur-kos:AccomodationCategory (accommodation category), estur-kos:typeOfAccomodationRate (accommodation rate type), estur-kos:OffersAdditionalAccomodationService (offers additional service), and estur:PriceClass (price category).

A concept relevant to city tourism is estur:HistoricalOrCulturalResource (historical or cultural resource), which encompasses museums, monuments, and shrines, among others. It is a subclass of estur:Place; consequently, it relates to estur:ContactPoint and estur:Location, and its estur:Description is also represented, as it is a type of estur:TourismEntity.
